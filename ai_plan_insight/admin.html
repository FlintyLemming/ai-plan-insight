模型别名

模型价格

成本按每个原始模型 ID 的单价计算，价格自动从 LiteLLM / OpenRouter / models.dev 获取； 这里只列出这三个源都查不到价的模型，填了才会计入成本。 单位 USD / 百万 Token，照抄各家定价页即可。

推送认证

POST /api/push/v2/{instance_id} 与 POST /api/usage/report 共用这一个 token。

显示设置

push 模式的订阅卡片在最后一次推送后超过该时长会从面板隐藏；fetch 模式卡片不受影响（始终展示）。单位为小时，允许小数，最小 0.5（30 分钟）。

管理密码

至少 8 位。修改成功后其他设备的登录会全部失效。

导入导出

导出的 JSON 含明文凭据，请妥善保管；它不包含管理密码。
